# Quantum Computing Lecture Notes 

This repository accompanies our Quantum Computing course and collects the lesson materials and executable notebooks used throughout the lectures. It is designed to take learners from the essentials—bra–ket notation, computational basis states, tensor products, and core single-/two-qubit gates—to foundational circuit-building skills through worked examples such as Bell-state preparation and quantum teleportation, with clear mathematical derivations alongside code you can run and modify. 

Beyond the basics, the repo also includes modules on key early quantum algorithms and concepts, including Deutsch / Deutsch–Jozsa, Bernstein–Vazirani (including a recursive perspective), and an introduction to the Quantum Fourier Transform with connections to the classical DFT/FFT.
